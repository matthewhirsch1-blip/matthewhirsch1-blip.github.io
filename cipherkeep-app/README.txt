CIPHERKEEP: standalone web app

Put this whole folder on any web host, then open the link on the phone.
iPhone: open the link in Safari, tap Share, then "Add to Home Screen".
Android: open the link in Chrome, tap the menu, then "Add to Home screen" or "Install app".

Progress saves on the device. Profile icon > Backup code moves progress between devices.
After the first visit the game also works offline.
